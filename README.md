# Library Catalog API

Асинхронный REST API для управления библиотечным каталогом.

Приложение позволяет создавать, получать, изменять, удалять и фильтровать книги. При создании книги API может автоматически дополнить её сведениями из Open Library.

## Технологии

- Python 3.11+
- FastAPI
- PostgreSQL
- SQLAlchemy 2.0
- asyncpg
- Alembic
- Pydantic
- HTTPX
- Poetry
- Docker Compose
- Pytest
- Ruff

## Возможности

- создание книги;
- получение книги по UUID;
- получение списка книг;
- фильтрация по названию, автору, жанру, году и доступности;
- пагинация списка;
- обновление книги;
- удаление книги;
- проверка уникальности ISBN;
- автоматическое обогащение данных через Open Library;
- создание книги даже при недоступности Open Library;
- интерактивная документация OpenAPI.
